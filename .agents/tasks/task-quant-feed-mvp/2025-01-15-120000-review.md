# QuantFeed — AI-powered economic news analysis platform (greenfield)

A full-stack Next.js 14 application that aggregates Indian and international news via RSS, summarizes articles with OpenAI, builds a force-directed graph of economic relationships, and offers a pathway simulator predicting micro-to-macro economic cascades. The entire app is built for Vercel deployment with graceful degradation to mock data when API keys are absent.

Watch for: the JSON-file data store uses synchronous filesystem I/O that will silently fail on Vercel's read-only serverless filesystem (confirmed); the cron endpoint is unauthenticated when `CRON_SECRET` is unset, allowing anyone to trigger the full AI pipeline and burn OpenAI credits (confirmed); the `/api/news/fetch` POST route has no authentication at all, exposing the same pipeline to arbitrary callers (confirmed); the `NetworkGraph` component resolves article details from the client-side mock import rather than from the graph API response, so node-click details will be wrong once real data is served (confirmed).

**Verdict**: NEEDS_CHANGES

## High-level view

The data persistence layer writes JSON files to a `data/` directory using `fs.writeFileSync`. Vercel serverless functions have a read-only filesystem outside `/tmp`, so every `saveArticles`, `saveEdges`, and `saveDailySummary` call will throw in production. The app won't crash — it falls back to mock data on reads — but no real data will ever persist between invocations, making the entire backend pipeline a no-op once deployed.

The cron and news-fetch endpoints represent an unauthenticated write path into the AI pipeline. `/api/cron` checks `CRON_SECRET` only when the env var is set; if omitted, the auth check is skipped entirely rather than denying access. `/api/news/fetch` has no auth at all. Together, these let anyone POST to the fetch endpoint and trigger unbounded OpenAI API calls.

The `NetworkGraph` component bypasses the API when looking up article details for the node-detail panel, reading from the imported `mockArticles` constant regardless of what data the graph API returned. The pathway simulator's confidence adjustment is purely cosmetic — it scales probabilities by the ratio of toggled inputs but doesn't call the `/api/analysis/simulate` endpoint, so the simulation is client-side arithmetic on static data rather than an AI re-analysis.

<summary>Issues (7)</summary>

1. **Filesystem store fails on Vercel** — `lib/news/store.ts` uses synchronous `fs` writes to `./data/`. Vercel serverless has a read-only filesystem. Migrate to `/tmp` (ephemeral), Vercel KV, or an external database for persistence.
2. **Cron endpoint unauthenticated when CRON_SECRET is unset** — The `if (process.env.CRON_SECRET && ...)` pattern skips auth entirely when the env var is absent. Invert the logic: deny access unless the secret is set AND matches.
3. **`/api/news/fetch` POST has no authentication** — Anyone can trigger the full RSS-fetch-and-OpenAI-analysis pipeline. Add a shared secret or restrict to internal invocation.
4. **NetworkGraph resolves node details from mock import** — `selectedArticle` is looked up in the client-bundled `mockArticles` array, not from the graph data or an API call. With real data, clicks will show nothing or stale mock content.
5. **PathwaySimulator doesn't call the simulate API** — Confidence adjustments are local arithmetic. The `useSimulation` hook exists but is never wired up, so the feature is cosmetic.
6. **No rate-limiting or cost cap on OpenAI calls** — `batchSummarize` fires one request per article in parallel (`Promise.allSettled`). A large RSS pull (100+ articles) produces 100+ concurrent OpenAI requests with no throttle.
7. **`saveEdges` overwrites rather than appends** — Each fetch cycle replaces the entire edges file, losing historical relationship data. `saveArticles` deduplicates; edges should too.

## Filesystem persistence and Vercel's read-only environment

The data layer in `lib/news/store.ts` calls `fs.writeFileSync` and `fs.readFileSync` against `path.join(process.cwd(), "data")`. On Vercel, `process.cwd()` resolves to a read-only deployment bundle. Writes will throw `EROFS` or silently fail depending on the Lambda environment. The only writable location is `/tmp`, which is ephemeral and not shared across invocations.

This means the cron job fetches articles, summarizes them, extracts relationships, then loses all of it when the function exits. The `GET` endpoints always fall back to mock data in production. Either use `/tmp` as a cache (accepting it's ephemeral), or switch to a persistent store — Vercel KV, Supabase, or any external service. The store module's interface is clean enough that swapping the implementation behind `readJsonFile`/`writeJsonFile` is low-friction.

## Unauthenticated AI pipeline exposure

```typescript
// app/api/cron/route.ts
if (
  process.env.CRON_SECRET &&
  authHeader !== `Bearer ${process.env.CRON_SECRET}`
) {
  return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
}
```

When `CRON_SECRET` is undefined, the entire auth block is skipped — fail-open. The safe pattern:

```typescript
const secret = process.env.CRON_SECRET;
if (!secret || authHeader !== `Bearer ${secret}`) {
  return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
}
```

The `/api/news/fetch` POST endpoint has no authentication whatsoever. It orchestrates the full pipeline: RSS fetch → AI summarize (N API calls) → relationship extraction → daily summary → pathway analysis. A single unauthorized POST could generate dozens of OpenAI API calls.

## NetworkGraph data lookup mismatch

```typescript
// components/NetworkGraph.tsx
import { mockArticles } from "@/lib/mock-data";
const selectedArticle = selectedNode
  ? mockArticles.find((a) => a.id === selectedNode.id)
  : null;
```

The component receives `graphData` as a prop (fetched from `/api/graph`), but when a node is clicked, it looks up article details from the statically-imported mock data. Once the store contains real articles with different IDs, the `find` call returns `undefined` and the detail panel shows nothing. Fix: include article metadata in the graph node objects returned by the API, or fetch article details on click.

## PathwaySimulator is disconnected from the simulation API

The `useSimulation` hook in `useApiData.ts` correctly POSTs to `/api/analysis/simulate` with selected article IDs. However, `PathwaySimulator.tsx` never imports or calls it. Instead:

```typescript
const getAdjustedConfidence = (baseConfidence: number): number => {
  const activeRatio = activeInputs.size / articles.length;
  const adjustment = (activeRatio - 0.5) * 20;
  return Math.min(100, Math.max(0, Math.round(baseConfidence + adjustment)));
};
```

Toggling events changes displayed percentages via arithmetic, but the underlying pathway data never changes. The UI implies it's running a simulation; it isn't.

## Unbounded parallel OpenAI calls

```typescript
// lib/ai/summarizer.ts
const results = await Promise.allSettled(
  articles.map((article) => summarizeArticle(article))
);
```

A typical RSS pull from 12 sources at 10 articles each yields ~120 articles — 120 concurrent `gpt-3.5-turbo` requests. OpenAI's rate limits (especially on free-tier accounts) will throttle most of these, producing a cascade of errors that all fall back to the original text. A concurrency limiter (batches of 10) would produce more reliable results.

## Edge data loss on each fetch cycle

```typescript
export function saveEdges(edges: EconomicEdge[]): void {
  writeJsonFile("edges.json", edges);
}
```

Each cron cycle overwrites the previous relationship graph with only the latest batch's relationships. Historical connections disappear. If the goal is a growing knowledge graph (which the neural-network visualization implies), edges should be appended and deduplicated, matching the pattern used by `saveArticles`.

## RSS feed reliability

Several configured RSS URLs are known to be unstable or access-restricted: Bloomberg's RSS feed (`feeds.bloomberg.com/markets/news.rss`) has been defunct for years; FT's RSS requires authentication for most content; Reuters' agency feed URL format changes frequently. In practice, the "international" category will likely return zero articles consistently. A health-check or source-status indicator would surface this to users rather than silently falling back to mock data.
